# Чашка Конвея

Игра «Жизнь» в браузере со своими правилами. Открой `index.html` — сборка и сервер не нужны.

- Правило пишется в поле сверху: `B3/S23`, `B36/S23`, `B2/S/C3` (C — число состояний, клетки угасают несколько поколений), или в старом виде `23/3`.
- Окрестность Мура (8 соседей) или фон Неймана (4), края можно замкнуть в тор.
- Размер доски, случайное засевание с нужной плотностью, рисование мышью или пальцем.
- Готовые узоры и загрузка своих в формате RLE (правило из строки `rule = …` тоже подхватывается).
- Клавиши: пробел — пуск и пауза, → — шаг, C — очистить.
